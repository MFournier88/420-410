# 📝 Examen : Le Luminaire Connecté "Duo-Smart-AP"
### Matériel authorisé :
- Site du cours
- Raspberry pi
- Cellulaire pour vérifier votre page html uniquement
- w3school pour le javascript uniquement <a target="_blanck" href="https://www.w3schools.com/js/">Lien</a>

**Contexte :** Vous devez configurer un Raspberry Pi pour piloter **deux** zones d'éclairage indépendantes (LED 1 et LED 2) via une interface web mobile.

### 1. Prérequis Réseau (3 pts)
* **Mode AP :** SSID nommé `Exam-IoT-DUO-VOTRENOM`.
* **Réseau :** IP statique `192.168.17.1`.
* **Serveur :** Flask sur le port `5000`.

### 2. Montage Électronique (3 pts)
* **Bouton :** Branché sur le **GPIO 6** (Contrôle global ON/OFF).
* **LED RGB #1 :** Vert ➔ **26** | Rouge ➔ **19** | Bleu ➔ **13**
* **LED RGB #2 :** Vert ➔ **21** | Rouge ➔ **20** | Bleu ➔ **16**

### 4. Travail Backend (app.py)

#### A. Serveur Flask & PWM (6 pts)
Le serveur doit maintenant gérer un dictionnaire de pins pour les deux LEDs :
```python
# Exemple de structure suggérée pour app.py
LEDS = {
    1: {'r': 12, 'g': 13, 'b': 18},
    2: {'r': 23, 'g': 24, 'b': 25}
}
```
1. **Route `POST /api/set_rgb` :** * Doit recevoir `id`, `r`, `g`, et `b`.
    * Doit appliquer le PWM uniquement à la LED correspondante à l'ID.
2. **Route `GET /api/led_state` :** * Renvoie si le système est en mode "ON" ou "OFF" suite à l'appui sur le bouton.

#### B. Logique du Bouton 
* Le bouton sur le **GPIO 6** doit éteindre ou allumer les **deux** LEDs simultanément (Toggle global).
